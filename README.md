# Учебный проект "Курсовая работа 2 Трекер самолетов"
## Контекст
Программа, которая собирает данные о самолетах в воздушных пространствах тех стран, которые вы выберете.
## Установка
Клонируйте репозиторий
```
git clone git@github.com:fess88888/Coursework_2
```
## Модуль main
Реализовано меню для работы пользователя с программой:
1. Получить самолёты по стране (и сохранить в JSON)
2. Топ N самолётов по высоте
3. Фильтр по стране регистрации
4. Фильтр по диапазону высот
5. Показать все сохранённые самолёты
6. Удалить самолёт по позывному
0. Выход
### Модуль api.py
Абстрактный класс API и реализации
### Модуль models.py
Модель самолёта, валидация, сравнение
### Модуль storage.py
Абстракция хранилища и JSON-реализация
## Тестирование
Все основные модули проекта покрыты тестами, что позволяет обеспечивать стабильность и надежность кода. Тесты находятся в папке tests, и их можно запустить командой:
```
pytest --cov=src --cov-report=html
```
### Покрытие тестами
 1. Покрытие тестами составляет 70% и более.
 2. Основные модули имеют высокий уровень покрытия, подтверждающий корректность их работы.
 3. Отчет о покрытии можно найти в папке htmlcov, открыв файл index.html в браузере.
### Подробности
 1. Тесты включают проверку всех критических функций.
